# Мастерская по обжарке кофе «Кварта» (Минск)

Современный, индивидуальный и быстрый веб-лендинг для независимой мастерской по обжарке кофе «Кварта» в Минске.

Сайт ориентирован на прямую конверсию: знакомство со свежей обжаркой микропартиями по 5 кг, выбор из пяти строго выверенных предложений (моносорта, дрип-пакеты, регулярная подписка), прозрачные условия доставки/самовывоза на ул. Короля, 9 и надежная отправка заявок с валидацией белорусских номеров, защитой от дубликатов, сбором рекламной атрибуции (UTM/кликовые ID) и опциональными Telegram-уведомлениями.

---

## 1. Стек технологий

- **Фреймворк**: [Next.js](https://nextjs.org/) (App Router, React 19, Server Components & Dynamic API Routes).
- **Язык**: TypeScript с максимальной строгостью типов.
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/) v4 с кастомными токенами крафтовой палитры (`globals.css`).
- **Типографика**: Google Fonts (`Lora` для выразительных заголовков, `Inter` для основного текста) с полной поддержкой кириллицы.
- **Иконки**: `lucide-react`.
- **База данных**:
  - **Production**: PostgreSQL (рекомендовано Neon Serverless PostgreSQL с бесплатным тарифом).
  - **Dev/Test Fallback**: локальное персистентное файловое хранилище с мьютексами и дедупликацией при отсутствии переменной `DATABASE_URL`, что гарантирует мгновенный запуск и прохождение тестов без обязательного подключения к облаку.
- **Тестирование**: [Vitest](https://vitest.dev/) (23 автоматических теста: валидация белорусского телефона, дедупликация 10 минут, гонки запросов, сохранение UTM, соответствие цен ТЗ).

## 4. Настройка базы данных

### Вариант 1: Бесплатный PostgreSQL в Neon (Рекомендуется для Production)
1. Зарегистрируйтесь на [Neon.tech](https://neon.tech/) (бесплатный тариф).
2. Создайте новый проект (например, `kvarta-coffee`).
3. Скопируйте строку подключения `Connection string` (выберите вариант `Pooled connection` для serverless окружения Vercel).
4. Укажите ее в `.env` (или в настройках переменных окружения Vercel):
   ```env
   DATABASE_URL=postgresql://user:password@ep-sample-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
5. **Автоматическая инициализация схемы**: таблица `leads` и составной индекс `idx_leads_phone_created` создаются **автоматически** при первом обращении к API через метод `ensurePgSchema()` в `src/lib/db.ts`. Дополнительно запускать ручные миграции не требуется.

### SQL-схема таблицы заявок
Если вы хотите накатить таблицу вручную через SQL Editor:
```sql
CREATE TABLE IF NOT EXISTS leads (
  id TEXT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  phone_normalized VARCHAR(20) NOT NULL,
  interest_type VARCHAR(50) NOT NULL,
  comment TEXT,
  product_context VARCHAR(200),
  utm_source VARCHAR(100),
  utm_medium VARCHAR(100),
  utm_campaign VARCHAR(150),
  utm_content VARCHAR(150),
  utm_term VARCHAR(150),
  gclid VARCHAR(150),
  yclid VARCHAR(150),
  fbclid VARCHAR(150),
  landing_page_url VARCHAR(500),
  referrer_url VARCHAR(500),
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_leads_phone_created ON leads(phone_normalized, created_at DESC);
```

### Вариант 2: Локальная разработка без внешней БД
Если переменная `DATABASE_URL` не задана, приложение автоматически сохраняет заявки в локальный файл `.data/leads.json` с поддержкой мьютексов и проверки 10-минутных дубликатов. Это позволяет запускать проект и прогонять автотесты без внешнего интернета.

## 5. Защита от дубликатов (10 минут) и Race Conditions

В соответствии с требованиями ТЗ:
1. Запрещены повторные заявки с одного и того же нормализованного белорусского номера (`+375XXXXXXXXX`) в интервале **10 минут**.
2. В PostgreSQL используется транзакционный рекомендательный замок `pg_advisory_xact_lock(hashtext(phone_normalized))`. При одновременной отправке двух параллельных запросов они сериализуются на уровне БД: первый запрос создает запись, второй видит свежую запись и возвращает HTTP 409 Conflict.
3. Пользователю выводится понятное дружелюбное сообщение:
   > *«Заявка с этого номера уже отправлена за последние 10 минут. Менеджер скоро свяжется с вами!»*

## 6. Отслеживание рекламного трафика (UTM & Click IDs)

При первом визите на страницу модуль в `OrderForm.tsx` считывает из строки запроса параметры:
- `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`
- `gclid` (Google Ads), `yclid` (Яндекс Директ), `fbclid` (Instagram / Facebook)
- `document.referrer` и текущий URL страницы

Метки кэшируются в `sessionStorage`, поэтому даже если посетитель скроллит страницу, переходит по внутренним якорям или кликает по кнопкам сортов перед отправкой заявки, рекламный источник не теряется и сохраняется в базе данных.

## 7. Уведомления в Telegram

Уведомления отправляются через официальный Telegram Bot API на сервере:
1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте ваш Telegram Chat ID (или ID группы) через [@userinfobot](https://t.me/userinfobot).
3. Добавьте переменные в `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   TELEGRAM_CHAT_ID=123456789
   ```
4. **Отказоустойчивость**: блок отправки в Telegram обернут в `try/catch`. Если токен не задан, Telegram недоступен или вернул ошибку, **сохранение заявки в базе данных не прерывается**, а пользователю гарантированно возвращается статус успешного приема заявки.

## 8. Пошаговая публикация на Vercel

1. Загрузите код в Git-репозиторий (GitHub / GitLab / Bitbucket).
2. Зайдите в панель [Vercel](https://vercel.com/) и нажмите **Add New Project**.
3. Выберите ваш репозиторий. Фреймворк определится автоматически как **Next.js**.
4. В разделе **Environment Variables** добавьте:
   - `DATABASE_URL` (строка подключения Neon Postgres).
   - `TELEGRAM_BOT_TOKEN` (опционально).
   - `TELEGRAM_CHAT_ID` (опционально).
5. Нажмите **Deploy**.
6. После деплоя откройте публичный URL и выполните тестовую отправку заявки с белорусским номером.

## 9. Лимиты бесплатных тарифов

- **Neon Free Tier**:
  - 0.5 GB хранилища (достаточно для ~500 000+ текстовых заявок).
  - Бесплатный вычислительный пул с автоматическим переходом в спящий режим при бездействии.
  - Потенциальные расходы: 0 $ в пределах лимитов.
- **Vercel Hobby**:
  - Бесплатный хостинг с поддержкой Serverless Functions и Fast Data Transfer (100 GB/мес).
  - До 100 000 вызовов Serverless Functions в день.
- **Telegram Bot API**:
  - Полностью бесплатно без ограничений на текстовые сообщения для одного канала/чата.

## 10. Известные ограничения и чеклист перед коммерческим запуском

Перед запуском платной рекламы владельцам мастерской (Ане и Дмитрию) необходимо:
1. **Юридические реквизиты**: на странице `/privacy` и в футере внести официальные данные оператора (наименование ИП/ООО, УНП, юридический адрес).
2. **Контактные телефоны мастерской**: если мастерская решит публиковать входящий номер телефона для звонков клиентов или мессенджеры (Telegram/Instagram), их можно добавить в шапку и подвал через `Header.tsx` и `Footer.tsx`. По умолчанию на сайте нет вымышленных номеров, используется только телефон клиента в заявке.
3. **Договор с курьерской службой**: согласовать график доставок по пятницам и тарифы для заказов до 50 BYN.
